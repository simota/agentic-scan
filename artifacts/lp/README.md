# agentic-scan landing page

A static LP introducing agentic-scan (12 read-only review skills for AI agents).

On 2026-11-19 the brand was rebuilt in the "terminal / agent" direction.

- The wordmark is `r--` (the permission string for read-only).
- A monospace typeface carries the brand.
- The colors are the severity colors used by the skills' own dashboards.
- Every terminal output on the page is the result of a command that was actually run.
- The product screens are real, generated by each skill's `make demo`.

## Location and how to open

- Source: `site/` (`index.html`, `ja/index.html`, `styles.css`, `main.js`, `assets/`)
- Run:

  ```sh
  cd site && python3 -m http.server 8765 --bind 127.0.0.1
  # http://127.0.0.1:8765/
  ```

- Build: not needed (no dependencies and no build step)

## Languages

- English is the default: `site/index.html`. The Japanese page is `site/ja/index.html`.
- Each page links to the other from the header (`日本語` / `English`) and declares the pair with `hreflang`. There is no automatic redirect by browser language.
- The English page shows the English samples (`examples/findings.sample.json`) and dashboards rendered in English (`assets/en/`); the Japanese page shows the Japanese samples and dashboards (`assets/`).
- `main.js` picks the copy-button text from the page's `lang`.
- The evaluation, QA and screenshots below were made on the Japanese page before the English page existed.

## Final evaluation

- Internal score 89 / 100 (progression after the rebuild: 64 → 78 → 82 → 86 → 89). The scoring rationale and why it did not reach 90 are in `pdca-report.md`.
- Lighthouse (lab measurement, served locally): Performance / Accessibility / Best Practices / SEO are all 100 on both mobile and desktop. Mobile LCP is 1.1s, CLS is 0.
- ui-deslop detector: 0 unresolved hits.
