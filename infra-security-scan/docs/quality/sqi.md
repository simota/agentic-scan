# SQI — Software Quality Improvement Index (infra-scan)

評価基準・重み・測定条件は **改善作業の前に** このファイルで確定し、改善前ベースラインと同じコミットで
固定した。改善後の再採点は同じ基準で行い、結果は末尾「改善後」に追記する（基準本文は改変しない）。

SQI はこのリポジトリのための独自ルーブリックであり物理量ではない。数値は「ルーブリック評点」
「実測値」「専門家（AI）評価」を区別して記録する。実ユーザーテストは実施していない。

## 0. 評価対象と条件（固定）

| 項目 | 固定値 |
|---|---|
| 対象コード | `skills/infra-scan/scripts/*.py`（ベンダー品 `scan_report_kit/` は上流で変更する契約のため評価対象外。ただし生成 UI の見え方には含まれる） |
| UI | `render.py` が生成する `dashboard.html`（対話型）と `assessment.html`（印刷用。PDF はこの HTML の印刷） |
| データ | `examples/findings.sample.json`（en）、`examples/findings.sample.ja.json`（ja）、スケール用 `tools/make_big.py`（1,009 件） |
| ビューポート | 1280 / 1024 / 768 / 390 / 320 px、ライト・ダーク（`prefers-color-scheme`） |
| ブラウザ | 同梱 Chromium（Playwright）、axe-core 4.10.2 |
| 代表タスク | T1 最も深刻な未解決事項を見つける / T2 検出事項の詳細とソース抜粋を開く / T3 観点・プロバイダで絞り込む / T4 LLM 用にコピー / T5 観点の未確認（カバレッジの穴）を読む / T6 印刷用報告書を開く |
| 変更シナリオ | S1 ベースラインルール追加 / S2 抜粋の秘匿判定ポリシー変更 / S3 スキーマ項目追加 / S4 ダッシュボード表示変更 / S5 HCL パーサ変更 |
| 重み | SQI = 0.25·DQI + 0.25·AQI + 0.25·VQI + 0.25·UXQI（全領域対象。重み変更なし） |
| 採否条件 | `make check` 全成功、axe 違反の新規発生なし、性能中央値の悪化が測定ノイズ（±10%）を超えない、既存 CLI の入出力・終了コード不変 |

測定ツールは `docs/quality/tools/`（スキル外。Node の Playwright と axe-core が必要）。

エビデンス: E0 未検証 / E1 コード・画面観察 / E2 再現可能な静的解析・自動テスト・体系的手動検証 / E3 実測・障害注入・複数の独立根拠。
