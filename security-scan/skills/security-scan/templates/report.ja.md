### レベルの読み方

<!-- scripts/render.py の legend_* ラベル（描画されるページと同じ文）から写したもの。変えるときは両方を揃える。 -->

| 重大度 | 条件 |
|---|---|
| High | 匿名または通常のログイン利用者が、どのアカウントにもある権限だけで、他者の重要データ（クラウンジュエル）の閲覧・改ざん、アカウント乗っ取り、認証や決済の回避、コード・SQL・コマンドの実行に到達できる。インターネットに公開されたサポート終了のランタイム・フレームワーク、悪意あるパッケージも含む。 |
| Medium | High と同等の影響だが攻撃者が制御できない条件が1つ必要（被害者の操作や被害者固有の情報、未確認の設定、管理者以外の特権ロール）、または価値の低いデータや業務ルールへの直接の影響。 |
| Low | 多層防御の不備、価値の低い情報の露出、または管理者・内部者・起こりにくい連鎖を要する経路。 |
| Info | 攻撃経路のない堅牢化の提案。 |

| 確度 | 意味 |
|---|---|
| Confirmed | 読んだコードで条件が示され、デプロイ時の設定に依存しない。 |
| Environment-dependent | デプロイ時の設定（プロキシ、信頼するヘッダー、デバッグフラグ、ストレージの ACL）次第で成立する。確認すべき設定を指摘に明記する。 |
| Suspected | 兆候はあるが未確認。何を確かめれば確定するかを指摘に明記する。 |

重大度と確度は別々に判定します。確度によって重大度は上下しません。攻撃者が制御できない条件が1つ増えるごとに重大度は1段階下がります。
